Spectra Documentation
---------------------

Currently **KEA** offers the following spectral estimation techniques:

* Fourier/Periodogram (FFT)
* Blackman Tukley/Correlogram (BT)
* Difference of Gaussian (DoG)
* Equivalent Spectrum (ESF)
