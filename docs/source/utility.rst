Utility
-------

**kea** provides additional utility methods such as:

* binning; which is used for both generating the angle-integrated and angle-averaged spectra as well as reducing the number of data-points in a 1D function.
* fitting; primarily interpolating/calculating values in logarithmic-space
* functions; provides mathematical descriptions of power spectral forms for the synthetic fields
* geometry; generating grids etc,
* plotting; tools to help beautify plots
